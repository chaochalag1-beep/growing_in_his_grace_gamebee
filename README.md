# Growing in His Grace — Bible Quiz Millionaire

Mobile-first multiplayer Bible quiz for Android browsers and Acode. Read `SETUP.md` before use.

**Quick start:** configure `firebase-config.js`, enable Firebase Anonymous Authentication, publish `database.rules.json` to Realtime Database, then host the folder over HTTPS (GitHub Pages recommended). Direct `file://` opening will not work because the app uses JavaScript modules and Firebase.

This is a starter project. The included client-side Firebase rules are permissive and are not cheat-proof for competitive events.
